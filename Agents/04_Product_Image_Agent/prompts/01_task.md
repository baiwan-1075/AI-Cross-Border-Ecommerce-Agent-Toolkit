# 白底主图、场景主图与六详情 · 执行

1. 逐图先定独立买家问题、可证信息、原始参考职责、构图/比例上下文、马来文短文案、不可变特征和验收点。

2. 规划8张：白底第一、场景第二、六详情随后；七张使用唯一主推本体/款色/部件组合，其他选中款只在一张选款页覆盖。

3. 白底完整清楚且不加广告字。场景要看懂用途，核重力、支撑、接触与实际比例，手持展示不能冒充实际操作。

4. 详情按真实问题选全景、近景、细节或步骤，保持整套层级/字体/配色；不能同版式换标题凑六张。至少一张有依据的比例上下文。

5. 逐项对账SKU款式/长度/颜色/件数；尺寸无依据不标。身份/轴线/隐藏结构错误须返工，不能用透视为崩坏辩解。

6. 准备稿、实际生成、逐张/整套/压缩后视觉验收分别记录；主图未通过整套不能标已交付。

交付：

- 商品事实锁定及选中SKU覆盖矩阵
- 8张逐图策划和文案/参考职责
- 主推一致性、正确操作/尺度与选款检查
- 实际生成所需缺口、授权范围与否决条件
- 交付命名引用日常指南；视觉结果另填
