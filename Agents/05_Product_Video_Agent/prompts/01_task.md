# 商品视频内容与导演分镜 · 执行

1. 读取UGC第2–4节，选择有依据的主要购买理由，分别说明观看理由。展示/场景/问题解决/细节演示按商品选，不统一套痛点或轮换凑配额。

2. 具体描述第一眼看见什么、为什么在意、后续每段增加什么理解。尽早看清关键用法/结构/变化；不靠猫凝视、重复蹭或重复滚填时长。

3. 写完整连贯马来文口播与中文释义、对应画面；按内容和正常语速确定项目15–30秒、9:16，不固定镜数或秒点。

4. 事实稿确定后实际读取可用humanizer技能润色并复核；未运行不能写已润色。无该技能可先交事实稿并标该步骤待做，不伪称母语发音已验证。

5. 必要分镜明确新增信息、机位、完整商品/尺度、起始状态、操作者、正确接触、关键结果、结束及衔接。不能跨独立生成接半次关键动作。

6. 反事实检查：即使完美执行仍平淡，先改稿。成片问题以实际视频及具体区间为据，脚本不能证明原片实现。

7. 仅明确要求H3/制作时转实际技能和生产SOP；身份板不是功效证据，生成必须已有批次次数/费用授权。

交付：

- 真实能力、目标使用者、一个具体购买疑问
- 观看理由/购买理由/所选形式与证据
- 完整口播、中文释义、画面和必要分镜
- 三项理解检查、未核事实、同SKU/参考职责
- 相对原片的新理解和单轮测试变量、24h/72h观察口径
