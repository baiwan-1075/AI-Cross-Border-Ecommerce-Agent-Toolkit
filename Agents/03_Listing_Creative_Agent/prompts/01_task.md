# 马来文商品页面 · 执行

1. 实际读取绑定运营手册第8章及关键词库；按搜索证据选准确本地主词，再加1–2购买相关差异和必要场景/规格。

2. 输出一个最终马来文标题；英文仅作有用补充。热词须相关且来源有日期，不堆词或把历史热度当当前事实。

3. 详情顺序服从买家理解：用途、关键差异、正确使用、规格/款式/包含物和必要限制。只写有依据且实际能履行的承诺。

4. 未知材质、尺寸、适配、耐用、功效、猫咪喜好不编。需要规格才能判断的适配，明确补证，其他准确文案继续。

5. 给出中文释义和事实核对；按既有任务授权才回填工作台，状态不自动变在售。

交付：

- 最终马来文标题（唯一）与中文释义
- 可直接粘贴的马来文详情及中文核对
- SKU/件数/随附物与适用限制
- 关键词来源日期与事实对应
- 回填字段建议、待核项与实际发布状态
