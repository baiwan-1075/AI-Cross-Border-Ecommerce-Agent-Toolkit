# 产品策略与经济性 · 执行

1. 确认本体/款色/部件/件数，列可见事实、供应声明、实物证据和未知。一个主要购买理由不等于整个商品只能有一个用途。

2. 先核采购、国内运费、货代、包材有无重复；买家承担运费和平台补贴只抵扣一次。税种、税基、封顶及当前资格单独核。

3. 调用绑定的现役定价工具，保留输入/配置/代码哈希与时间；不复制上游利润率、广告率、退货率或平台费默认值。

4. 区分保本成交、目标贡献成交、活动价、券后价和反推上架价。目标贡献不是平台净结算或月净利润。

5. 拿同款同行价反算本店贡献；只提出换供货、包装/物流优化、目标取舍或退出建议，不能删除真实费用把亏损算没。

交付：

- 主推SKU锁定和销售单位、真实差异与购买理由
- 成本来源、缺失字段和重复计入核对
- 计价工具/保存参数来源及条件输出；可比价格口径
- 目标与保本对照、同行价下贡献和约束
- 交给03/04/05的可宣称事实与禁止推断
