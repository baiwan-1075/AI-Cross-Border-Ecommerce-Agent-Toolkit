# 评论、咨询与售后回流 · 执行

1. 区分本店真实反馈、同行公开评论、供应商说明和合成示例。同行反馈只作需求线索，不写成本店买家证据。

2. 按实物质量、适配/尺寸、操作、交付数量、页面误解、物流和服务逐项归因，可多标签且保留无法确定。

3. 先核原页面与事实，不能将所有差评都归为用户不会用；商品缺陷交供货核查，实际客服/退款按专门授权。

4. 提取重复购买疑问及频数/分母，保持样本边界，不从一条反馈推广全部需求或许诺效果。

5. 给出可直接使用的马来文修补文字/图片或视频问题，列应改模块和依据；不发消息、不诱导评价、不代处理订单。

交付：

- 样本来源/时间/SKU与统计分母
- 逐项归因、证据及不确定性
- 购买疑问与可直接用的马来文修补稿
- 回流文案/图片/视频/供货的具体动作
- 需要客服或订单处理的授权依赖
