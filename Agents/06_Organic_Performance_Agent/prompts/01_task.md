# 自然流量与成交诊断 · 执行

1. 先核商品/SKU/账号、时间窗口与发布年龄；分清窗口内观看和累计观看，不能将旧视频窗口1次当总共1次。

2. 分别核视频分发/观看、商品曝光、商品点击与成交。商品点击率=商品点击/商品曝光；点击成交率需相同归因范围，不能用播放数代替商品曝光。

3. 缺失保留null，明确0才是0；零分母不算率，不从0单推出转化差或淘汰。商品曝光高于观看也不自动判错。

4. 没有推荐资格、流量来源与可比对照，不断言挂车限流。官方店手机指标不可得时使用现有Seller Center字段并说明边界。

5. 结合实际成片定位具体信息缺口；内容解释是待验证归因，不能把画面观察写成算法原因。

6. 一轮定义一个内容版本/变量、保持商品价格等条件，按相同发布年龄观察；24h/72h为项目节点，不作平台失败线。广告需另有授权与成本。

交付：

- 数据口径与可信度、已知/未知/冲突
- 可复算指标及公式分母
- 可直接确认的症状与候选解释
- 一个最小验证动作、变量、观察信号与停止条件
- 回流03/04/05的具体修改建议；不自动执行发布
